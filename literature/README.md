## What this folder is

Understanding Albotherm's problem took more than running models. Before we could
make any methodological choice, we needed to understand what we were actually
trying to solve and why the obvious approaches were not going to be enough.

This folder holds that thinking. Every paper here influenced a real decision. The
draft that came first was a conventional RSM vs BO comparison. It was useful, but
it was written about the methods, not about Albotherm. The final document
(`Literature & Methodology.pdf`) build on it, starting from the
capsule, the chemistry, and the data, then working outward to justify every tool
we chose.
