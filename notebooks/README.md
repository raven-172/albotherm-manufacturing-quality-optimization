# Notebooks Folder

This folder is where all the jupyter notebooks are. they cover the data cleaning, merging, processing, eda, etc. Within each folder are version folders that show the evolution of the project with older and newer notebooks.

[Data Cleaning](<Data Cleaning/>) contains the notebooks going through the cleaning of the data. \
[Data Merging](<Data Merging/>) contains the notebooks where the dataset is merged. \
[Data Analysis](<Data Analysis/>)contains the data analysis notebooks. \
[Hypothesis Testing](<Hypothesis Testing/>) contains the hypothesis testing notebooks. \
[Model](<Model/>) contains the models and modelling notebooks.

# Version in folfer
In most subfolders of the 'notebook' folder, there are smaller folders divided into 'Ver_1' and 'Ver_2'.

In which:
[Ver_1]
These folders contain the work we performed using the old data processing method (specifically, "../Ver_1/albotherm_01.ipynb" and "../Ver_1/albotherm_02.ipynb" are the two old data processing methods) and using the old processed datasets (../data/processed/Ver_1/). The notebooks of [Data Analysis], [Hypothesis Testing] belonging in to "../Ver_1/" will use these data sets.

[Ver_2]
These folders contain the work we performed using the old data processing method (specifically, ../Ver_2/albotherm_01_1.ipynb and ../Ver_2/albotherm_02_1.ipynb are the two old data processing methods) and using the old processed datasets (../data/processed/Ver_2/). The notebooks of [Data Analysis], [Hypothesis Testing], [Model] belonging in to "../Ver_2/" will use these data sets.
